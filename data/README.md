# Dataset

This project uses the **Bank Marketing** dataset from the UCI Machine Learning Repository.

- Dataset page: https://archive.ics.uci.edu/dataset/222/bank+marketing
- Expected file: `bank-full.csv`
- Expected shape: 45,211 rows × 17 columns
- CSV delimiter: semicolon (`;`)

Download the dataset from the UCI page and place `bank-full.csv` in this directory before running the notebook.

The raw CSV is excluded from Git using `.gitignore`; this keeps the repository lighter and lets users obtain the original data directly from its source.
